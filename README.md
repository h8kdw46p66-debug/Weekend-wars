# Weekend Wars – Münster (testversie)

Een lokale HTML-prototype van Weekend Wars. Open `index.html` in een browser of publiceer de repository als statische website op Vercel.

## Let op
- De app bewaart gegevens in de browser (localStorage), **niet** in een gedeelde database.
- Verschillende spelers zien niet automatisch elkaars wijzigingen.
- Dit is een demonstratie, geen beveiligde multiplayer-app. Gebruik geen echte gevoelige persoonsgegevens.

## Vercel
Importeer deze repository via Vercel → Add New → Project. Framework Preset: **Other**. Root Directory: `./`. Build Command: leeg / geen build. Output Directory: leeg / standaard. Klik Deploy.
